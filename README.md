# Саратов на Волне — карта фестивалей и событий

Карта: **https://denispolulyakh.github.io/saratov-na-volne/**

Все события карты хранятся в одном файле Excel — `data/events.xlsx`, фотографии лежат в папке `data/photos`. Чтобы изменить карту, достаточно поправить таблицу и загрузить её сюда через сайт GitHub. Через 1–2 минуты карта обновится сама. Программировать и устанавливать ничего не нужно.

---

## 1. Скачайте актуальную таблицу

Всегда начинайте с последней версии файла с GitHub, иначе можно затереть чужие изменения.

1. Откройте папку **data**, затем файл **events.xlsx**.
2. Справа над содержимым нажмите кнопку скачивания (**Download raw file**).
3. Откройте файл в Excel.

## 2. Добавьте или измените событие

Одна строка на листе **«События»** — одно событие. Подсказки по каждой колонке есть на листе **«Справка»**.

| Колонка | Что писать | Обязательно |
|---|---|---|
| id | Уникальный код латиницей без пробелов: `fest-008`, `exc-002`, `exh-001`. Не должен повторяться | да |
| название | Как увидит турист | да |
| категория | Выбрать из списка: фестиваль, выставка, экскурсия, природа | да |
| дата_начала | Первый день, формат `ДД.ММ.ГГГГ` | да |
| дата_окончания | Последний день. Для однодневного события — та же дата | да |
| время | Свободный текст: `10:00–18:00`, `начало в 19:00` | нет |
| адрес | Адрес или ориентир | да |
| координаты | Точка на карте, см. раздел 3 | да |
| описание | Текст для карточки события | да |
| как_добраться | Остановка, номера транспорта, сколько идти пешком | желательно |
| фото | Имена файлов из папки `data/photos`, см. раздел 4 | нет |
| ссылка | Сайт события или страница с билетами | нет |

Как карта работает с датами:

- Турист выбирает даты приезда и отъезда и видит события, которые идут хотя бы в один из этих дней.
- Прошедшие события (дата окончания раньше сегодняшней) скрываются автоматически. Удалять их из таблицы не обязательно.
- Чтобы убрать событие с карты совсем, удалите его строку.

## 3. Координаты

Вставляйте координаты в колонку **координаты** как скопировали — порядок и формат карта поймёт сама.

**Яндекс Карты** (проще всего):

1. Найдите место, нажмите на точку правой кнопкой мыши.
2. Выберите **«Что здесь?»**.
3. Нажмите на координаты вверху карточки — они скопируются, например `51.532179, 46.035468`.

**2ГИС:** откройте карточку места и скопируйте из адресной строки браузера кусок вида `46.035468%2C51.532179`.

Проверка: для Саратова одно число около **51**, другое около **46**. Если чисел нет или их одно — событие не появится на карте.

## 4. Фото

1. Назовите файл понятно, без пробелов, например `Башня_историй.jpg` или `palitra-1.jpg`. Кириллица допустима.
2. Формат JPG или PNG, желательно до 1 МБ (больше — карта дольше грузится на телефоне).
3. В колонку **фото** впишите имя файла с расширением: `Башня_историй.jpg`.
4. Несколько фото — через точку с запятой: `palitra-1.jpg; palitra-2.jpg`. Первое фото — главное.

## 5. Загрузите изменения на сайт

**Таблица:**

1. На GitHub откройте папку **data**.
2. Нажмите **Add file → Upload files**.
3. Перетащите `events.xlsx`. Имя должно быть ровно `events.xlsx` — тогда старый файл заменится.
4. Внизу нажмите **Commit changes**.

**Фото:**

1. Откройте папку **data → photos**.
2. **Add file → Upload files**, перетащите фотографии (до 100 файлов за раз, каждый до 25 МБ).
3. **Commit changes**.

Порядок не важен, но удобнее сначала загрузить фото, потом таблицу.

## 6. Проверьте

1. Подождите 1–2 минуты. Ход обновления виден во вкладке **Actions**: зелёная галочка — готово.
2. Откройте карту и обновите страницу с очисткой кэша: **Ctrl+F5** на компьютере, на телефоне — закройте вкладку и откройте ссылку заново.
3. Нажмите **«Все»** рядом с датами, чтобы увидеть все предстоящие события.

## Если событие не появилось

- Вверху списка слева есть строка **«Пропущено строк в Excel: N»** — наведите на неё мышь, там будет причина (нет координат, неверная дата).
- Проверьте, что выбранные даты поездки пересекаются с датами события, и что категория события не выключена в чипах сверху.
- Проверьте, что загрузили файл именно в папку `data` и с именем `events.xlsx`.

## Правки с флешки (вместо загрузки через сайт)

На флешке лежит вся папка `КАРТА`, а папка `site` внутри неё — копия этого репозитория. Можно править события прямо на флешке, проверить их офлайн и опубликовать одним кликом. Нужен компьютер с установленным git и входом в GitHub.

1. Двойной клик по **update.bat** — забрать последнюю версию с GitHub. Делайте это перед каждой правкой.
2. Отредактируйте `site\data\events.xlsx`, положите фото в `site\data\photos`. Сохраните и закройте Excel.
3. Двойной клик по **start.bat** — карта откроется в браузере без интернета. Проверьте, что всё на месте.
4. Двойной клик по **publish.bat** — изменения уйдут на GitHub, сайт обновится через 1–2 минуты.

Важно: выберите один способ правок — либо через сайт GitHub, либо с флешки. Если смешивать, всегда начинайте с **update.bat**, иначе публикация не пройдёт. Копируя флешку, переносите папку `КАРТА` целиком, вместе со скрытой папкой `site\.git`.

## Что не трогать

Файлы `index.html`, `server.py` и папки `lib`, `map` — это сама карта. Для наполнения нужны только `data/events.xlsx` и `data/photos`.

## Доступ

Загружать файлы может только владелец репозитория и приглашённые им участники. Владелец добавляет человека в **Settings → Collaborators → Add people** по логину или почте GitHub, тот принимает приглашение из письма.
